Roadmap

Планы развития сайта, по приоритету.

Hotfixes/Small features Fixes or easy features

  • В футтере добавить ссылку на github сайта.

Features Standard features that need to be implemented

  • Объединение аккаунтов для пользователей с несколькими аккаунтами (частично уже завершено).
  • Подпись темы дичфеста, чтобы все знали что за тема (через админ-аккаунт).
  • Добавить страницу карты со ссылками на tmx и trackmania.io (вместо прямого редиректа).
  • Новые задачи по вкладке карты появятся после её появления.

Global features Big features for big update

  • Вкладка Players. Первоначально: сбор рекордов и топ игроков. Новые задачи по вкладке игроков появятся позже.
  • Опубликовать backend в open-source. Надо думать над безопасностью, документацией и гайдами.

Planning Need to think about whether it can be canceled or changed.

  • Объединение карт под общими темами (а не по кампании) от имени админа. Надо подумать над дизайном и оценить сложность
  • Бинго. Оценить сложность и целесообразность.
  • Различные интеграции с ботами. Оценить сложность и целесообразность.
  • Социальный контент. Комментарии, подписки на авторов и так далее. Развить и оценить сложность и целесообразность.
  • Какая-нибудь статистика. Онлайн за сегодня, last-seen пользователей, и так далее
